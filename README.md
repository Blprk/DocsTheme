# Google Docs Theme Switcher

A Chrome extension that enhances your Google Docs experience with beautiful themes and canvas filtering support.

## Features

- Multiple built-in themes (Light, Dark, Sepia, Solarized, High Contrast, and more)
- Real-time theme switching
- Canvas filtering for consistent theming
- Smooth transitions between themes
- Persistent theme preferences

## Installation

1. Clone this repository
2. Open Chrome and navigate to `chrome://extensions/`
3. Enable "Developer mode" (toggle in the top-right corner)
4. Click "Load unpacked" and select the extension directory

## Usage

1. Open any Google Docs document
2. Click the extension icon in the Chrome toolbar
3. Select your preferred theme from the dropdown

## Available Themes

- **Light** - Default Google Docs theme
- **Dark** - Dark theme for reduced eye strain
- **Sepia** - Warm, paper-like theme
- **Solarized** - Professional color palette
- **High Contrast** - Improved readability
- **Midnight Blue** - Deep blue theme
- **Forest Green** - Nature-inspired theme
- **Warm Amber** - Cozy amber theme

## Development

1. Install dependencies:
   ```bash
   npm install
   ```

2. Make your changes to the source code

3. Load the extension in Chrome:
   - Go to `chrome://extensions/`
   - Enable "Developer mode"
   - Click "Load unpacked" and select the extension directory

## Building for Production

To create a production build:

```bash
npm run build
```

This will create a `dist` directory with the production files.
